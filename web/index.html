gist-search

Search every gist created by a GitHub user (default: rust-play). Metadata search runs in Rust-compiled WASM; content search runs in your browser. Use GitHub-style qualifiers: user:, language: — e.g. user:rust-play language:rust fn main. Re-syncs are incremental (only gists updated since the last sync are fetched). Star a gist with the ☆ button (needs a token with the gist scope).
